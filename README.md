firstbit

My coding class assignments, collected in one place. Each assignment is kept in its own folder so it's easy to find and run.

How to Run

Clone the repo and open the assignment you want:

bash
git clone https://github.com/Shivam7Jaiswal/firstbit.git
cd firstbit/assignment-01

For Java files, compile and run:

bash
javac Main.java
java Main
